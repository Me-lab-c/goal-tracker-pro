## Project Overview
Goal Tracker Pro is a role-based employee goal management and performance tracking system designed for organizations to efficiently manage employee objectives, monitor progress, and improve productivity.

The application provides separate dashboards and functionalities for Admins, Managers, and Employees with secure authentication and responsive user interface support.

---

## Features

- Role-based Authentication
- Admin, Manager, and Employee Dashboards
- Goal Creation and Tracking
- CRUD Operations
- Performance Analytics
- Responsive Mobile-Friendly UI
- Notifications Panel
- Secure Backend API Integration
